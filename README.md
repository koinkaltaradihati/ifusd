# Indonesia Finance USD (IFUSD)

Official repository for **IFUSD (Indonesia Finance USD)**, a secure, decentralized digital asset utility framework designed for regional financial settlement and liquidity integration.

## 📌 Token Specifications
* **Token Name:** Indonesia Finance USD
* **Token Symbol:** IFUSD
* **Decimals:** 18
* **Total Supply:** 316,993,900 IFUSD
* **Standard:** BEP-20 / ERC-20
* **Network:** BNB Smart Chain (BSC) / EVM-compatible

## 📄 Smart Contract Features
* **OpenZeppelin Standard:** Built on industry-standard, secure cryptographic and access control libraries.
* **Ownable Access Control:** Administrative functions (such as minting) are restricted to the designated owner wallet.
* **Burnable:** Allows token holders to reduce circulating supply by burning tokens securely.

## 🚀 Deployment & Verification
1. Compile the contract using **Remix IDE** or **Hardhat** with Solidity `^0.8.20`.
2. Deploy to BNB Smart Chain using an injected Web3 provider (MetaMask, Trust Wallet, etc.).
3. Verify contract source code on BSCScan for full transparency and on-chain trust.
